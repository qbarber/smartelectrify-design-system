# Replit.md

## Overview

This is a React component library for building home electrification ROI (Return on Investment) calculators. Generated by Magic Patterns, it provides reusable, accessible UI components for address input, equipment selection, financial projections, and data visualizations. The library helps users understand the costs, savings, and environmental impact of home electrification upgrades like heat pumps, solar panels, and batteries.

## User Preferences

Preferred communication style: Simple, everyday language.

## System Architecture

### Frontend Architecture
- **Framework**: React 18 with TypeScript
- **Build Tool**: Vite 5.2 for fast development and optimized production builds
- **Styling**: Tailwind CSS 3.4 with a custom design system (Bonsai-inspired emerald/stone color palette)
- **Component Structure**: Organized into primitives (Button, Input, Select, Card) and composite components (forms, dashboards, charts)

### Design System
- **Color Palette**: Primary emerald green (#059669) with warm stone neutrals for backgrounds and text
- **Typography**: Inter font family with 16px base size
- **Utility Functions**: Uses `clsx` and `tailwind-merge` for conditional class handling via a `cn()` helper

### Component Organization
```
src/
├── src/
│   ├── primitives/     # Base UI elements (Button, Input, Select, Card)
│   ├── components/     # Composite components (forms, dashboards, charts)
│   └── lib/           # Utilities and design constants
├── ComponentPreview.tsx  # Development preview/demo page
└── index.tsx            # App entry point
```

### Data Visualization
- **Library**: Recharts for charts (LineChart, AreaChart)
- **Components**: GridIntensityChart (24-hour carbon intensity), SavingsChart (15-year cost comparison)

### Icons
- **Library**: Lucide React for consistent iconography

## External Dependencies

### Core Dependencies
- **React/React-DOM 18.3**: UI framework
- **Recharts 2.12**: Charting library for data visualizations
- **Lucide React 0.522**: Icon library
- **clsx/tailwind-merge**: CSS class utilities

### Development Dependencies
- **Vite**: Build tool and dev server (configured for host 0.0.0.0, port 5000)
- **TypeScript 5.5**: Type safety
- **Tailwind CSS**: Utility-first CSS framework
- **ESLint**: Code linting with React hooks and refresh plugins

### No Backend/Database
This is a purely frontend component library with no backend services, APIs, or database connections. All data is passed through component props.
